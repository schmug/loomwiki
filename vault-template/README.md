# Loomwiki Vault

> Auto-generated by Loomwiki on first deploy. The wiki you're reading lives
> here as plain markdown. You can `git clone` this repo at any time and the
> contents will mirror what the Loomwiki UI shows.

## Layout

- `AGENTS.md` — the contract between this vault and the Loomwiki ingest
  agent. Operators may edit the §11 sub-sections; the rest is part of the
  product surface and should not be hand-edited.
- `wiki/` — markdown pages, one per concept/decision/entity. Frontmatter
  per `AGENTS.md` §6.
- `rooms/` (M5+) — daily chat-log archives, committed by the worker cron
  at 02:00 UTC.

## Editing

The recommended way to edit pages is via the Loomwiki UI — it round-trips
the YAML frontmatter cleanly and prevents schema drift. If you edit pages
directly via `git`, run `git push`; the UI's optimistic-locking layer will
detect the change on the next save.

## Status

Loomwiki is currently at version `0.0.1` (POC). Wikilinks
(`[[page-name]]`) render as plain code-fenced text in v0.0.1 — they
become resolvable links in v0.1.
