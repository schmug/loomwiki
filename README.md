# Loomwiki

A Cloudflare-native team workspace where chat is the input and a git-backed wiki is the output. Open-source, one-click self-hostable on Cloudflare.

**Status:** Pre-alpha. POC under active construction. See [`SPEC.md`](./SPEC.md) for the full specification and [`docs/SECURITY.md`](./docs/SECURITY.md) for the threat model.
